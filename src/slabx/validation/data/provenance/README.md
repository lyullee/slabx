# Validation data: provenance

Every observation used in this work came from a published source, downloaded
from its official site. **None of it is redistributed here.**

That is a decision, not a finding. No permission was sought from any rights
holder, and nothing below should be read as a determination that
redistribution would be prohibited. Where the position was not already
explicit, the material was excluded rather than pursued, so that publication
does not wait on correspondence.

What is published instead is enough to repeat the work: where each value came
from, which table it sits in, and what was done to it.

---

## Three files

| file | answers |
|---|---|
| `source_manifest.csv` | who published it, where it lives, what the terms say |
| `variable_mapping.csv` | which table it came from and what was done to it |
| `publication_status.csv` | derived: publish or withhold |

The third is generated by `examples/provenance_status.py` from the first two.
Rights and scientific transformation stay in separate files, and the verdict
is derived rather than typed, so it cannot drift from the position it is
supposed to follow.

```
27 files, 881 rows

  PUBLISH     1 files    28 rows
  WITHHOLD   26 files   853 rows
```

The one published file is `smedis_inventory.csv` -- the list of trials
excluded from the validation set and the reason for each, written for this
work.

## Where the observations are looked for

Not inside the package. `SLABX_VALIDATION_DATA`, or `./validation-data` if
that is unset:

```bash
export SLABX_VALIDATION_DATA=/path/to/your/data
```

```
$SLABX_VALIDATION_DATA/
    smedis/*.xls          the SMEDIS standardised spreadsheets
    lng_pool_trials.csv   derived tables, per variable_mapping.csv
    ...
```

Keeping them outside the installed package is deliberate: files under `src/`
are one careless `git add` or one `package-data` line away from being
published, and these are the user's copy rather than ours.

Tests that need an observation skip when it is absent and name the file they
wanted. Nothing fails for want of data.

## The sources

### SMEDIS -- 10 files, 724 rows

Standardised trial spreadsheets from the EU SMEDIS project (1996-1999),
coordinated by HSE with CERC and EDF. Downloaded from
https://admlc.com/smedis-dataset/, a public page with direct download links.

The page records that the rights holders -- Bertrand Carissimo (EDF) and HSE
-- made the material available so it could be shared with the dispersion
modelling community through ADMLC. Use is plainly intended. Re-hosting
elsewhere is a separate question that was not put to them.

A revision history is published alongside (`sdbrev.pdf`, documenting versions
to 2.4) and lists corrections to several trials used here -- `ti08`,
`dat231`, `eec171`, `pg8`, `pg17`, `lat49` among them. Check you hold the
same version.

The accompanying SMEDIS Final Report is distributed as a **DRAFT** and is
cited as such.

### PHMSA -- 8 files, 51 rows

The LNG Model Evaluation Protocol validation database (03903-RP-002 Rev B)
and the Final Environmental Assessment for Phast 8.4, from official US DOT
sites. The validation database is contractor-authored, so the usual position
on US Government works does not automatically apply.

The Maplin Sands values here are **PHMSA's published figures**, not the
proprietary originals, which were never obtained.

### Jack Rabbit III / ADMLC -- 5 files, 41 rows

Arc-maximum concentrations and the Desert Tortoise equivalent-source
conditions, from direct file URLs on admlc.com. Crown Copyright is asserted
on ADMLC material.

### Witlox et al. (2013) -- 2 files, 21 rows

Arc concentrations and comparison statistics, *Chemical Engineering
Transactions* vol. 31. The journal assigns copyright of each article to
AIDIC Servizi S.r.l.

### McQuaid & Roebuck (1985) -- 1 file, 16 rows

Thorney Island Phase I conditions, EUR 10029 EN, hosted by ADMLC.

### The original SLAB source

Not in this repository. Its header forbids charging a fee for distribution
and forbids inclusion in any commercial product -- a non-commercial
restriction that no OSI-approved licence permits. See
`golden/fortran/README.md` for how to obtain and build it.

## Two dates, kept apart

| column | meaning |
|---|---|
| `license_checked_date` | when the stated terms were read (2026-08-20) |
| `downloaded_date` | when the file was actually obtained |

`downloaded_date` and `terms_at_download` are **left empty** where no record
exists. They are not reconstructed from memory, and the checked date is not
substituted for them. An empty cell is more useful than a plausible one.

`downloaded_url` records the address the file was actually fetched from,
which for several sources is a direct file URL rather than the landing page
in `official_url`.

---

## If a link is dead

Search on the report number rather than assuming the data is gone. The
numbers are in `source_manifest.csv`, and this project once spent months on a
source it could not locate by URL but which was available under its
identifier.
